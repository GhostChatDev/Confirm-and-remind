# Design system

A calm, mobile-first notes app, with no dashboards or charts. A narrow desktop sidebar becomes a bottom navigation on small screens. Today presents a greeting, quick capture, and a simple task list; Notes, Upcoming, Review and Settings use the same compact page layout.

- Background `#f6f7f4`; surface `#ffffff`; border `#e0e5df`; text `#1d3027`; muted `#596d61`; accent `#28634c`; success `#296b4e`; danger `#a13d3d`.
- Font: system UI stack; body 16px, small 14px, heading 24px, page heading 32px; tabular numbers for dates.
- Spacing: 4, 8, 12, 16, 24, 32px. Corners: 10px and 18px.
- Components: navigation, page heading, card, button, labeled input, status chip, dialog, list row, empty state and notice. Focus rings and 44px touch targets are required.
